# 한국 핵심 수치 1차 자료 대조 검증 (verification_korea)

> **검증 방법(반드시 읽을 것)**
> - 검증일 2026-11-14. 기존 메모 2건(`korea_demographics_fiscal.md`, `korea_levers_macro.md`)의 핵심 수치를 1차 문서 원문(PDF·공식 웹페이지)과 대조했다. 원문은 curl로 내려받아 `pdftotext`로 추출한 텍스트에서 직접 읽었다.
> - 열람 성공: kosis.kr(인구상황판 연도별 계열), www.nabo.go.kr(보고서 PDF 5건, 보도자료 1건), www.korea.kr(기재부·기획예산처 보도자료 첨부 PDF 3건), www.kdi.re.kr(현안분석 PDF), www.bok.or.kr(이슈노트 초록 페이지), data.worldbank.org(지표 페이지 내장 데이터).
> - 열람 실패: kostat.go.kr, moef.go.kr, api.worldbank.org, population.un.org, index.go.kr, nps.or.kr, **file-cdn.bok.or.kr(한은 PDF 첨부파일 호스트)**, www.oecd.org·www.imf.org(403). 이 때문에 한은 보고서는 웹 초록만 확인했고 PDF 본문 수치는 확인하지 못했다.
> - 상태 표기: **확인** = 원문과 일치 / **불일치(정정값)** = 원문과 다름 / **부분확인** = 일부만 원문에 있음 / **원문 미확인** = 원문을 열지 못함.
> - "조사자 계산"이라고 쓴 값은 원문 수치로 직접 계산한 것이며 공식 수치가 아니다. AI 생산성 시나리오는 제외했다.

**정정이 필요한 항목 요약(상세는 각 절)**
1. 기재부 민감도 "5% vs 15%" 혼선 → 원문: 의무지출 순증분 △5% = 138.7%, △10% = 121.7%, **△15% = 105.4%**. 재량지출 △5% = 150.3%, △10% = 144.4%, △15% = 138.6%.
2. NABO 건강보험 재추계(2026-06-09) → 메모의 "2025년 적자·2028년 소진"은 틀림. 원문: **2026년 적자 전환, 2028년 말 누적준비금 7.6조원, 2029년 소진(△1.1조원)**.
3. 이자지출 → 메모의 "2026년 36.5조 → 2030년 53조, GDP 1.5%"는 국가재정운용계획 원문과 불일치. 원문(의무지출 내 이자지출): **2026년 33.6조(추경 33.7조) → 2027년 40.0조 → 2030년 48.9조원**.
4. 의무지출 연평균 증가율 8.5%는 **2026년 본예산 대비**(정부 표기). NABO는 추경 대비로 7.9%로 표기. 국세수입 13.4%(본예산 대비) vs 11.6%(추경 대비)도 같은 이유.
5. 2026년 국가채무비율 51.6%는 본예산 기준, 추경 기준은 50.6%. 두 메모가 서로 다른 값을 쓴 것은 기준 차이이며 둘 다 원문에 있음.
6. KDI "2047년 전후 역성장", "2025년 1.8%" → 원문 표현은 "2040년대 후반 소폭 역성장", "금년 1%대 후반". 2047·1.8이라는 숫자는 원문 본문에 없음.
7. 한은 환율 전가효과 자료는 독립 "BOK 이슈노트"가 아니라 **「경제전망보고서(2025년 2월)」의 [Box1]**(등록 2025-02-25). 수치(0.47%p 등)는 PDF 호스트 차단으로 원문 미확인.
8. 국민연금: NABO가 2026-06-18에 수정전망을 냄 → **2050년 적자 전환, 2069년 소진**(메모에 없던 최신값). 기재부 제3차 전망의 2048년/2064년은 원문 확인.
9. 메모의 "대체 계열"(2045년 68.4)은 별도 계열이 아니라 통계청 중위 추계의 2045년 값과 같다.

### Gaps
- 2022년 기준 이후의 통계청 신규 장래인구추계: 발표 사실을 확인하지 못했다. KOSIS 인구상황판 계열은 2072년에서 끝나고 2025년 값이 29.3으로 2022년 기준 추계와 같으며, NABO의 2026년 6월 문서들도 "국가데이터처 장래인구추계(2023.12.)"를 최신으로 인용한다. kostat.go.kr은 열리지 않아 보도자료 목록은 확인하지 못했다.
- 저위·고위의 2035년·2045년 노년부양비, 고령인구 2035·2045년 공식 절대값: KOSIS 통계표(DT_1BPA002 등) 직접 조회 실패.
- NABO 「NABO 인구전망 2025~2045」(2025-12-11, NABO 자체 추계)는 존재만 확인했고 내용은 열람하지 않았다 — [NABO 보도자료](https://www.nabo.go.kr/ko/notice/releasesView.do?idx=9014)
- UN WPP 원자료(population.un.org)는 차단되어 World Bank 경유로만 확인했다.
